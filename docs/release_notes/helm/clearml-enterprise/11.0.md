title: Version 11.0
---

:::important[Breaking Changes]
Starting with chart version 11.0.0, server containers run as a non-root user by default.

To avoid permission issues, follow the [required upgrade steps](../../../deploying_clearml/enterprise_deploy/helm_upgrade_11_0.md).
:::

### clearml-enterprise 11.0.3

**New Features and Improvements**
* Add support for specifying resources (CPU, memory, GPU requests/limits) in the `Apps` agent's base pod template, for 
  pods spawned to consume ClearML Apps tasks

### clearml-enterprise 11.0.2

**New Features and Improvements**
* Add option to expose Usage Aggregator via Ingress

### clearml-enterprise 11.0.1

**New Features and Improvements**
* Update `webserver` version to 3.29.3-1980


### clearml-enterprise 11.0.0

**New Features and Improvements**
* Update ClearML Enterprise Server to [3.29](../../clearml_server/enterprise/ver_3_29.md) (`apiserver`/`fileserver` 3.29.1-800, 
  `webserver` 3.29.1-1888, `usage-aggregator` 3.29.0-25)
* Set server containers to run as non-root user by default
* Update `clearml-enterprise-agent-k8s-base` to 1.31-3.0.0-434 and `clearml-agent-services-app` to app-1.3.0-79
* Add option to configure `containerSecurityContext` for ClearML Applications via `clearmlApplications.basePodTemplate.containerSecurityContext`

### clearml-enterprise-app-gateway 3.3.0

**New Features and Improvements**
* Mount a writable `emptyDir` volume on the proxy NGINX logs directory, so the pod can run under a non-root, random UID 
  (e.g. OpenShift restricted SCC)
* Add new `proxy.logsToStdout` value (default `true`) to send NGINX access/error logs to the container stdout/stderr
* Add new `extraVolumes`, `router.extraVolumeMounts`, and `proxy.extraVolumeMounts` values
